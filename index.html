Kamus Simbol & Tanda Baca Coding

Panduan lengkap arti simbol agar tidak bingung lagi

Simbol Dalam HTML (Struktur Bangunan)

HTML menggunakan Tag Pembungkus. Seperti kardus, ada bagian pembuka dan penutup.

< > (Kurung Siku Pembuka)
Memberitahu komputer: "Ini awal dari sebuah perintah/elemen baru". Contoh: <h1>
</ > (Tag Penutup)
Garis miring / artinya "Selesai/Tutup bagian ini". Contoh: </h1>
<!-- ... --> (Komentar HTML)
Catatan rahasia pembuat kode. Komputer akan mengabaikan teks ini di layar.
class="..." atau id="..."
Memberi label / nama identitas pada elemen HTML agar mudah diwarnai di CSS.

Simbol Dalam CSS (Cat & Dekorasi)

CSS bertugas mengatur tata letak, ukuran, dan warna.

. (Titik) & # (Pagar)
Titik . dipasang untuk memanggil nama class. Pagar # untuk memanggil id.
{ } (Kurung Kurawal)
Wadah/tempat menaruh semua aturan hiasan untuk elemen tersebut.
: (Titik Dua)
Artinya "yaitu". Menghubungkan hal yang mau diubah dengan nilainya. Contoh: color: red;
; (Titik Koma)
Tanda titik pemberhentian. Menyatakan satu baris aturan hiasan sudah selesai. Wajib ada!

Simbol Dalam JavaScript (Mesin & Logika)

JavaScript memberikan perintah interaktif saat diklik atau diinput.

// (Garis Miring Ganda)
Catatan penjelasan. Komputer tidak akan menjalankan teks apapun setelah tanda // ini.
" " atau ' ' (Tanda Kutip)
Memberi tahu komputer bahwa tulisan di dalamnya adalah Teks Biasa, bukan kode perintah.
( ) (Kurung Lengkung Aksi)
Wadah memberikan masukan/isi untuk sebuah perintah fungsi. Contoh: alert("Halo")
= (Sama Dengan)
Di JS, tanda = artinya memasukkan/menyimpan nilai ke dalam variabel (bukan matematika).
