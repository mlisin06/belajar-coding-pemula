Kamus Simbol & Tanda Baca Coding

Penjelasan detail arti simbol agar tidak membuat pusing

Simbol HTML (Struktur Bangunan)

< > (Kurung Siku Pembuka)
Awal perintah elemen baru. Contoh: <h1>
</ > (Tag Penutup)
Garis miring / artinya penutup bagian. Contoh: </h1>

Simbol CSS (Cat & Dekorasi)

{ } (Kurung Kurawal)
Wadah berisi aturan hiasan untuk elemen tersebut.
: dan ; (Titik Dua & Titik Koma)
: artinya "yaitu", dan ; adalah titik akhir perintah.

Simbol JavaScript (Mesin & Aksi)

// (Garis Miring Ganda)
Catatan rahasia. Teks setelah // diabaikan oleh komputer.
" " (Tanda Kutip Teks)
Memberi tahu komputer bahwa teks di dalamnya adalah tulisan biasa.
