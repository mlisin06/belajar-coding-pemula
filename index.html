Kamus Simbol & Tanda Baca Coding

Penjelasan detail arti simbol agar tidak membuat pusing

Simbol HTML (Struktur Bangunan)

< > (Kurung Siku Pembuka)
Awal perintah elemen baru. Contoh: <h1>
</ > (Tag Penutup)
Garis miring / artinya penutup bagian. Contoh: </h1>
<!-- ... --> (Komentar HTML)
Catatan rahasia pembuat kode. Komputer mengabaikan teks di dalamnya.
class="..." atau id="..."
Memberi label / nama identitas pada elemen HTML agar mudah dihias di CSS.

Simbol CSS (Cat & Dekorasi)

. (Titik) & # (Pagar)
Titik . untuk memanggil class. Pagar # untuk memanggil id.
{ } (Kurung Kurawal)
Wadah/tempat menaruh semua aturan hiasan untuk elemen tersebut.
: (Titik Dua)
Penghubung (Artinya "yaitu"). Contoh: color: red;
; (Titik Koma)
Tanda pemberhentian. Menyatakan satu baris perintah hiasan sudah selesai.

Simbol JavaScript (Mesin & Aksi)

// (Garis Miring Ganda)
Catatan rahasia. Komputer tidak akan menjalankan teks setelah tanda ini.
" " (Tanda Kutip Teks)
Memberi tahu komputer bahwa teks di dalamnya adalah tulisan biasa.
( ) (Kurung Aksi)
Wadah memberikan masukan/isi untuk menjalankan perintah aksi.
= (Sama Dengan)
Di JS, tanda = berarti **menyimpan nilai** ke dalam variabel.
